## 数据与能力边界

业务数据由 Go / SQLite 管理，凭据由原后端加密机制管理，不进入浏览器 localStorage。主题、密度、收藏、标签、连接展示备注以及分组颜色和图标属于按用户隔离的本机偏好，更换浏览器不会自动同步。

没有实时设备在线监测：手动 TCP 检测更新端口可达/不可达、检测时间及建连耗时，后台刷新保留本次页面结果；完整刷新后需重新检测，目标变化与用户切换会清理旧结果。TCP 连通性仅表示端口可达。概览统计来自后端保留的会话记录（保留窗口为 90 天），不是永久累计数据。
